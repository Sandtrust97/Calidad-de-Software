Adecuación & Eficiencia

Adecuación Funcional: Satisface las necesidades del usuario mediante completitud, corrección y pertinencia en las tareas.

Eficiencia: Desempeño estructurado considerando los tiempos de respuesta y la utilización de recursos del sistema bajo estrés.

Compatibilidad & Usabilidad

Compatibilidad: Interoperabilidad y coexistencia fluida dentro de ecosistemas compartidos de hardware y software.

Usabilidad: Interfaces construidas para ser entendidas, atractivas y capaces de proteger al usuario final contra flujos de error.

Fiabilidad & Seguridad

Fiabilidad: Alta disponibilidad, madurez del código y tolerancia para recuperar el estado deseado ante fallos imprevistos.

Seguridad: Garantía de confidencialidad, integridad estructural, trazabilidad de acciones y autenticidad del acceso.

Mantenibilidad & Portabilidad

Mantenibilidad: Código modular, altamente reusable y diseñado para ser modificado o analizado sin introducir nuevos defectos.

Portabilidad: Adaptabilidad y facilidad operativa para trasladar o instalar el sistema a través de múltiples entornos objetivos.

Funciones de Datos

  • ILF (Archivos Internos): Entidades lógicas de información que el sistema mantiene y actualiza internamente.
  • EIF (Archivos Externos): Datos cruciales referenciados para consulta, pero gestionados por APIs o sistemas externos.

Funciones Transaccionales

  • Entradas (EI): Procesos que ingresan al sistema para actualizar bases de datos internas.
  • Salidas (EO): Datos expuestos hacia el exterior tras aplicar cálculos o lógica de negocio profunda.
  • Consultas (EQ): Recuperación directa de información sin alteraciones en la persistencia de datos.

Complejidad Ciclomática

Evalúa el número de caminos independientes en el flujo de control. Matemáticamente equivale a condicionales + 1.

Alerta de Riesgo: Un valor superior a 50 revela código espagueti extremadamente difícil de mantener y probar mediante testing unitario.

Densidad y Mantenibilidad

Regla SLOC: Un bloque funcional no debería superar las 20-30 líneas ejecutables para respetar la responsabilidad única.

Índice Combinado: Escala automatizada (0-100) que integra volumen, ramas lógicas y densidad de comentarios limpios.

Acoplamiento (CBO)

Cuantifica las dependencias directas entre componentes. Un valor CBO ≤ 5 es ideal para asegurar independencia.

Un acoplamiento alto genera un efecto dominó, donde un cambio mínimo rompe múltiples módulos del sistema.

Cohesión (LCOM)

Mide la correlación entre métodos y atributos internos. Una cohesión baja (valores altos) indica la presencia de un "Objeto Dios".

El código de calidad requiere fragmentar estas clases monolíticas para restaurar el Principio de Responsabilidad Única.

Jerarquía (DIT & RFC)

Profundidad DIT: Se recomienda mantener árboles de herencia cortos (≤ 3) favoreciendo la composición sobre la herencia.

Respuesta RFC: Una cantidad abrumadora de métodos ejecutables en cadena dispara los costos de testing e integración continua.
